Connect with a GitHub access token that can edit this repository. The token stays in this browser and is never saved to the site.

How to make a token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Pick an expiry date, generate, and paste the token here.
